## v0.0.0 release history reset

The Library source component restarts at semantic version `0.0.0`. This repository is a public distribution mirror: legacy 1.1.x GitHub Releases and release tags are removed by a one-time, explicitly marked GitHub Actions cleanup. The mirror's own source history is retained. New v0.0.0 release assets are published only after their upstream checksums have been verified.

The v0.0.0 source archive includes independently versioned metadata for all 18 SDLC role agents in `roles/agents.json` and excludes superseded design-preview screenshots. Verify the published `library-source.sha256` before using the archive.

Library v0.0.1 decision-memory source now includes 14 categorized `.memory/*.json` files, version-increment checks, and the single overwritten `RELEASE.md`.
